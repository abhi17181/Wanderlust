# 🏡 Wanderlust

A full-stack Airbnb-inspired web application that allows users to browse, filter, and list properties for rent — complete with an elegant UI, secure authentication, and smooth user experience.

---

## 🚀 Features

- 🔐 **User Authentication** — Secure login and signup system.  
- 🏘️ **Property Listings** — Users can explore or host rental properties.  
- 🎯 **Advanced Filters** — Search properties by location, price, and category.  
- 🖼️ **Attractive UI** — Modern, responsive design with smooth interactions.  
- 🗂️ **CRUD Functionality** — Add, update, and delete property listings.  
- 💬 **Dynamic Data Rendering** — Real-time updates for listings and filters.  

---

## 🛠️ Tech Stack

### Frontend:
- **EJS**
- **Tailwind CSS** / **Styled Components**  
- **Axios** for API calls

### Backend:
- **Node.js**  
- **Express.js**

### Database:
- **MongoDB** (Mongoose ODM)

### Other Tools:
- **JWT Authentication**
- **Multer / Cloudinary** for image uploads  
- **Dotenv** for environment configuration
